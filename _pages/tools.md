Interactive teaching tools I've built for [Michigan Math and Science Scholars (MMSS)](https://lsa.umich.edu/mmss), a summer neuroimaging program for high school students. Each tool gives students hands-on experience with a real analysis pipeline, running entirely in the browser.

## fMRI Analysis Tool

A browser-based tool walking students through fMRI preprocessing and first-level analysis, from raw data to an activation map.

[Launch tool](https://mollysimmonite.github.io/mmss-fmri-tool/){:target="_blank" rel="noopener"}

## EEG/ERP Analysis Tool

A browser-based tool for preprocessing and analyzing EEG data, built around a P300 oddball paradigm recorded with Human SpikerBoxes.

[Launch tool](https://mollysimmonite.github.io/mmss-eeg-tool/){:target="_blank" rel="noopener"}

## HCP Data Explorer *(in progress)*

A SQL-based tool for querying and exploring Human Connectome Project data.

## Dashboard *(in progress)*

A Tableau dashboard for visualizing course and study data.
